# PR media

Images and GIFs embedded in pull request descriptions of this fork, one folder per PR
(`pr-<number>/`). This branch holds no source code and is never merged.

Bug-fix GIFs are recorded in the live FreeCAD GUI through freecad-mcp: "before" runs a
FreeCAD-start build, "after" the PR build, and captions show values measured in FreeCAD.
